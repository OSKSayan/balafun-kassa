# balaFUN Касса

Мобильная касса официанта для ресторана balaFUN. Одностраничное веб-приложение (PWA-стиль), работающее полностью офлайн: все заказы, меню и статистика хранятся локально в браузере телефона (IndexedDB), без сервера и без интернета после первой загрузки страницы.

## Возможности

- Вход по PIN-коду
- Открытие заказов, добавление блюд из меню (разделы «Бар меню» / «Кухня меню»), изменение количества, удаление позиций
- Пробитие чека и история закрытых заказов с возможностью удаления
- Касса: выручка за сегодня, количество заказов, средний чек, график за 7 дней
- Редактор меню: категории и блюда можно добавлять, редактировать и удалять прямо в приложении, включая фото блюда с камеры или из галереи

## Использование

Открой `index.html` (например, через GitHub Pages) в браузере телефона и добавь страницу на главный экран.
